# SD2.5 提示词助手 V6.17Flash｜DSH 插件分发包

下载本仓库 ZIP（Code → Download ZIP），解压后把整个目录交给 DSH 中可管理插件的助手，按《给AI的安装指令.md》安装。发布 Release 时可上传同内容压缩包。

这是一个新增的**可选 Agent 预设插件**，不是 DSH 软件本体，也不替换原有助手。安装、更新、重新启用都不自动设为默认助手；用户需要时自行在新会话中选择“SD2.5提示词助手_V6.17Flash”。

助手版本为 V6.17Flash，插件分发版本为1.0.1。核心、模板及知识库原文保持不变；仅将安装路径与技能入口改为便携分发，并取消技能入口中强制调用外部计数字数脚本的要求。

## 保留的能力

- A 提示词、B 商量审查、C 改镜、D 九列分镜；A 每镜七字段，人物情绪与对白合入连续表演。
- 7 个知识库：01 与13—18，保留原版知识库编号及完整输出样例；不混入Pro的八字段或人物陪演库。
- 原台词与已确认剧情锁定；素材按图N@文件名绑定、独立音频编号；默认不打开图片、音频、视频。
- 自然环境音与真实动作拟音正常描述，默认无BGM、附加字幕与无来源装饰音。
- 按 EP集数/EP集数-场次-Part序号.txt 保存；一次成稿所有PART合计≤6500 Unicode字符（含空格换行）。
- 完稿后重新读取模板、逐项对照当前输入、修正并复核最后一稿；**不为成稿核对/计数执行外部脚本或要求扩大权限**，不虚报精确计数或视频效果。
- 工作说明默认中文，原台词保留原语种；个人偏好与知识库分离。

## 安装条件与步骤

面向具备 agent-preset、persona、文件/检索/技能及相关内置工具插件的 DSH。Node.js 18+ 仅用于一次性安装准备，DSH 插件管理仍遵循宿主权限；不提供无授权安装或绕过权限功能。

1. 解压到固定目录，不要在 ZIP 内直接运行。
2. 在 DSH 中打开此目录，用支持插件管理的助手读取《给AI的安装指令.md》。安装期间不要同时修改同一助手。
3. 确认目标 DSH 数据目录。默认使用 DSH_HOME 环境变量，否则使用当前用户的 .dsh；多配置/便携部署请显式指定 --home。
4. 执行 `node 安装准备.mjs --apply`，只放置资产；已有本版需用户确认后加 `--update`。默认不带 --apply 为只读预览。
5. 使用 DSH 的 plugin_manager 注册程序返回的 bundle 目录，检查 application 与诊断。**只运行准备程序不等于安装完成。**
6. 遵循 DSH 返回的重启提示；开启新会话，手动选择本助手。既有会话不会自动更换人格。

本包不是“把整个ZIP上传到任意插件安装入口就保证可用”的单文件插件；当前采用**资产准备 + DSH标准bundle注册**两步。注册时可能需要联网下载依赖，受DSH版本和权限影响。

## 新安装与更新

- 新安装：使用全默认个人层，不带发布者的个人偏好。
- 已有V6.17Flash：显式 --update 后逐字节保留个人偏好，完整旧目录先备份到目标DSH数据目录的 _backups/sd25-v617flash/时间戳。
- 从旧Flash迁移：显式 --update，按6.16.1Flash、6.16Flash等语义版本次序查找旧Flash个人偏好；不读Pro或.bak，不从未来版本倒迁。
- 有冲突仅说明，不擅改偏好。例如旧偏好关闭保存时，不强行开启保存。
- 不删旧版、Pro、其他助手和用户项目，不写profile配置，不切换默认助手。

若注册失败，不宣称成功：保留备份、报告诊断。回退时由DSH插件管理注销/禁用本bundle，再恢复相应资产并注册原版本；不要直接修改profile。卸载不自动删个人偏好或备份。

## 目录

- `payload/sd25-v617flash/bundle/`：只声明本助手的Cordis bundle；路径占位符由安装准备程序替换。
- `payload/sd25-v617flash/skills/`：技能入口、13份原始Markdown及INDEX索引。
- `templates/`：全默认个人偏好模板。
- `安装准备.mjs`：安装阶段校验、路径适配、备份和偏好继承，不注册插件或改默认值。
- `文件校验.json`：发布资产字节数与SHA256；用于完整性校验，不是发布者签名。
