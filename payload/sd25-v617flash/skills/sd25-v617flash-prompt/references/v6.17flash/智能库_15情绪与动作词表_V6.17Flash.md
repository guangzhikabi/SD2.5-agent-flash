# 智能库_15情绪与动作词表_V6.17Flash

## 使用方法
情绪必须落到可见动作、姿态、视线、动作质感或对白方式；不只写情绪标签，不自动补夸张表情。

## 高频状态
### 强忍悲伤
保持日常动作，语流变短或收住，不自动哭泣。
### 压抑愤怒
动作受控，关键短语更重，语义组连贯，不逐字咬碎。
### 震惊
表面动作可短暂延续，随后停住、重新确认或延迟回应。
### 警觉
注意力在说话者、入口和危险来源之间切换，身体准备改变方向。
### 疲惫
动作幅度减少、反应延迟、语句省力，不自动闭眼或夸张叹气。
### 恐惧
保持距离、寻找出口、动作受限或声音压低，不自动尖叫或逃跑。
### 焦虑等待
反复确认时间、入口或物件，但动作有目的，不机械抖动。
### 怀疑与试探
问题逐步逼近，表面可平静，视线和停顿表现观察。
### 决心
动作明确、方向稳定，台词不必提高音量。
### 释然
控制逐步解除，动作恢复，不自动拥抱或大哭。
### 疼痛忍耐
动作保护受伤部位，发声受限，仍努力完成当前任务；不凭空增加伤情。

## 情绪转折
压抑 → 泄漏 → 恢复控制或失控；怀疑 → 观察 → 确认 → 接受或否认；期待 → 等待 → 落空 → 延迟反应。

## 词句级语气
需要控制表演的台词，在原句附近绑定说话情绪与态度、整句状态及必要关键词的具体说法。只标必要的重音、连读、收尾或升降调；普通中性对白不强加起伏，花括号内只保留原台词。

## 声音边界
自然环境音和真实动作拟音按场景和可见动作正常描述；BGM、转场音、情绪强调音和无来源装饰音效默认禁止。
