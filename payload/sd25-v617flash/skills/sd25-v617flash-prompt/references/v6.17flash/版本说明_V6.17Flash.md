# SD2.5提示词助手 V6.17Flash

## 本版定位
本版由V6.16.1Flash修订建立，原版本保留不变；改动参照V6.17Pro，按Flash的精简结构移植。本版沿用V6.10七个镜内字段和Flash精简知识库（01、13—18号）。

## 开工清单（新增）
助手运行在 DSH agent 中。新任务先查看工作区：列出图片、音频、视频和剧本文件，识别本次集数并使用已有或新建的EP集文件夹（如EP3，不补零，无法判断时先问）；只按文件名识别可绑定的人物、场景与音色素材，默认不打开图片、音频和视频，用户要求时才打开；剧本正常读取，外观特征只取自剧本、用户说明或已确认绑定；把素材与剧本角色对应，汇报集数、文件夹、编号与用途后再写提示词。规则见核心预设第3.1节。

## 成稿保存（新增）
A、C模式每个PART保存到对应集文件夹，命名“EP集数-场次-Part序号.txt”，如 EP3/EP3-2-Part1.txt，只存提示词正文；C模式覆盖对应文件，A模式覆盖前先提醒；D模式不自动保存。规则见核心预设第3.2节。

## 全局绑定写法（新增）
每个素材单独一行：
图1@院外02 绑定为医院院落场景参考。
图2@麦克斯 高定西装1 绑定为迈克斯（深棕卷发、深灰细条纹西装、蓝灰衬衫），面部与服装参考。
将音频1@迈克斯1 绑定为迈克斯的声音音色，只取音色，不继承原台词、背景音乐与背景声。
@后照抄工作区文件名（去扩展名）；“绑定为”前留空格；图片和音频按上传顺序分别编号。完整写法见输出模板“全局绑定写法”。

## 声音与文字规则
自然环境音和真实动作拟音正常描述；BGM、转场音、情绪强调音、无来源装饰音效默认禁止；用户明确要求静音时才写静音。
画面默认无对白字幕、自动字幕、人物姓名标签、水印和附加标识；用户明确要求的字幕及剧情需要的真实道具文字除外。

## 保留限制
完整提示词所有PART合计不超过6500字（核心第12节原文未改）；原台词、时码、动作与对白关系、连续性和七个镜内字段保持不变。文本检查不等于视频生成测试。
