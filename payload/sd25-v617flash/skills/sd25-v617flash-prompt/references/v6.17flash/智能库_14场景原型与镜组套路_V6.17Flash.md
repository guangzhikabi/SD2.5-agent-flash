# 智能库_14场景原型与镜组套路_V6.17Flash

## 用途
按场景空间和戏剧功能选择最少的镜头组合，不把原型当成剧情来源。

## 原型01 大空间/厅堂
先建立人物关系、可见出口和主要锚点，再用中景或近景推进信息，不持续使用大全景。

## 原型02 狭窄室内
利用门、墙、桌面、家具和人物距离表现压迫或回避，遮挡不能阻断关键动作和台词。

## 原型03 走廊与门口
适合等待、拦截、离场、偷听和追问；保持门两侧的空间关系。

## 原型04 户外开放空间
先确认人物相对位置和背景锚点，再选择固定观察、跟拍或横移；不因户外自动添加风、雾、夕阳或人群。

## 原型05 车辆/电梯等小空间
明确座位、视线和出口，保持狭窄空间中的距离与受光连续。

## 镜组01 对话与反应
建立关系 → 说话者表达 → 听者接收或继续动作 → 必要结果。

## 镜组02 对峙与沉默
保持双方空间关系，通过距离、视线、动作停止或延迟回应推进压力。

## 镜组03 接触与身体动作
建立位置 → 接触或动作发生 → 结果确认；不把物理阶段机械拆成固定镜数。

## 镜组05 跨空间移动
从已知位置经门、走廊或出口进入新区域，移动中更新位置、背景和已建立的自然环境音。

## 镜组06 离场与收束
准备离开 → 关系或声音阻滞 → 最后反应 → 保留未决状态。

## 选择检查
优先使用能看清当前事件和人物关系的最少镜头；正常交代不自动手持，结果出现后降低或停止运动。

## 声音边界
自然环境音和真实动作拟音按场景正常描述；BGM、转场音、情绪强调音和无来源装饰音效默认禁止。
